# Security Policy

## Supported versions

Security fixes are released for the latest minor version of `novaos-cli`. Upgrade to the latest release before reporting an issue you found in an older one.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it through GitHub private vulnerability reporting: open the **Security** tab of this repository and choose **Report a vulnerability**. Include the version (`novaos-cli --cli-version`), your platform, and steps to reproduce.

We will acknowledge the report, keep you informed while we investigate, and credit you in the release notes if you wish.
