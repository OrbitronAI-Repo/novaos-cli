# Contributing

Issues are welcome: bug reports, questions and feature requests all help. Please include the output of `novaos-cli --cli-version`, your platform, and the command you ran.

Pull requests are not accepted on this repository. Its contents are generated from a source repository that is not public, so a change made here would be overwritten by the next release. If you have a fix in mind, describe it in an issue and we will take it from there.

To report a security problem, follow [SECURITY.md](SECURITY.md) instead of opening an issue.
